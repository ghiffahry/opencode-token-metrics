How context composition is estimated

OpenCode does not expose exact category-level token attribution.

Provider-reported input tokens are used as the total reference.

Static context is estimated from available project sources including:

  • AGENTS.md
  • rules
  • SKILL.md
  • opencode.json

Remaining attribution uses available conversation, workspace, retrieval, and MCP metadata.
